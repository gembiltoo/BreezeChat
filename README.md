# 🌬️ BreezeChat

**Stay in your Minecraft server chat from your phone. No game needed.**

BreezeChat is a lightweight Minecraft: Java Edition chat client for Android. Join servers, chat, keep your accounts online in the background and watch your surroundings on a live minimap, all with very little battery and data.

> Fan-made project. Not affiliated with, endorsed by, or connected to Mojang or Microsoft.

---

## ✨ Highlights

- 💬 **Chat and commands** with chat filter, join commands and a repeating message
- 👥 **Many accounts at once**: offline and Microsoft sign-in, connect or leave them all in one tap
- 🌙 **Runs in the background**: keep playing other apps and games while your accounts stay online
- 🗺️ **Live minimap**: biome colours, nearby players and mobs, day/night clock, coordinates
- 🎒 **Inventory and movement**: walk, turn, jump, sneak, use items
- 🔁 **Auto everything**: auto login, auto respawn, anti-kick AFK, auto reconnect
- 🖼️ **Nice looking**: server cards with icons, skin heads, item pictures, bottom-sheet menus
- 💾 **Backup**: save your accounts and servers to a folder and restore them after reinstalling
- 🔔 **Update notice**: get told when a new version is out

## 🎮 Supported versions

BreezeChat works on servers from **1.19 up to 26.1**.

| Server version | How it works |
|---|---|
| 1.19.4, 1.20, 1.20.1 | Native support, full features |
| 1.19 – 26.1 (all other versions) | Connects as 1.19.4. Works on servers that accept older clients (for example with ViaVersion / ViaBackwards) |

Pick your server's version in the server form. If a server refuses the connection, it most likely does not accept older clients.

## 📲 Download

Get the latest APK from the [**Releases**](https://github.com/gembiltoo/BreezeChat/releases) page and install it. Android may ask you to allow installing from your browser or file manager.

## 🚀 Getting started

1. Tap **+** and add an account (offline name or Microsoft).
2. Add a server: address, version, and the Forge switch if the server needs it.
3. Tap the server card to join.
4. Open **Connections** to see and manage every session.

## 🔋 Staying online in the background

Some phones (Samsung and others) stop apps that run in the background. If your accounts get disconnected, turn off battery optimisation for BreezeChat. The **?** (Help) screen shows how.

## ⚠️ Known limitations

- Full features are native only on 1.19.4 – 1.20.1. Newer servers need to accept older clients.
- It is a chat client, not a game launcher. There is no 3D view, and the server may correct your position because the client only knows the top block of each column.
- Microsoft sign-in is not included in backups. Sign in again after restoring.
- Servers with extra anti-bot or mod checks may not accept the client.
